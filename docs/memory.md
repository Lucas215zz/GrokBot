# 长期记忆

让 Bot 记住你的偏好、习惯和过往经验，跨会话、跨重启都有效。

## 两级作用域

| 作用域 | 范围 | 例子 |
| --- | --- | --- |
| `user`（我的） | 本机所有 Bot 共享 | 「叫我老李」「始终用简体中文」 |
| `bot`（本 Bot） | 只影响当前 Bot | 「日报固定分三部分」 |

## 两个层级

| 层级 | 何时进入上下文 | 用途 |
| --- | --- | --- |
| `profile`（长期偏好） | **每次对话自动注入** | 称呼、语言、格式偏好、禁忌 |
| `log`（任务经验） | **不自动注入**，靠 `recall` 检索 | 做过的任务、踩过的坑、历史结论 |

设计理由：`profile` 有字符预算（3000），只放最稳定的偏好；琐碎经验放 `log`，
需要时再检索，避免每轮都塞进去撑爆上下文。

## Bot 怎么用

三个工具：

| 工具 | 用途 |
| --- | --- |
| `remember` | 记一条（指定 topic / tier / scope） |
| `recall` | 按关键词检索（含任务历史） |
| `forget` | 删除记错的一条（需 id） |

实测（第 1 轮交代偏好）：

```
工具: remember {"topic":"称呼","content":"用户希望被称为「老李」。","tier":"profile","scope":"user"}
      remember {"topic":"回答风格","content":"回答尽量简短，不要长篇大论。","tier":"profile",...}
回复: 记住了，老李。以后简短说。
```

实测（第 2 轮，**全新会话、零历史**）：

```
工具: （无）
回复: 记得，老李。
```

说明记忆确实是从磁盘读出来注入的，不是靠对话历史。

## 去重规则

同 `tier + topic` 视为同一条，**覆盖更新**而不是追加。
所以反复说「叫我老李」「叫我李先生」不会堆积，只留最新一条。

## 界面

「左栏 → 🧠 记忆」可：

- 按作用域 / 层级筛选
- 关键词搜索
- 手动新增、删除

## 数据在哪

```
%APPDATA%\Grok Bot\memory\
  user.json           全局记忆
  <botId>.json        单个 Bot 的记忆
```

## 当前限制

- 检索是**关键词子串匹配**，不是语义检索（没有向量库）
- `profile` 有 3000 字符预算，超出部分不注入（会提示用 recall 检索）
- 没有「记忆冲突检测」——同名 topic 直接覆盖，旧值不保留
- 没有自动摘要/压缩，长期使用需要手动清理 `log`

## 什么时候该记

好记的内容：

- 明确的偏好（称呼、语言、格式、长度）
- 稳定的环境事实（时区、常用路径、账号体系）
- 重复出现的约束（「不要用 emoji」）

不必记的：

- 一次性的任务细节（会话里已经有）
- 敏感信息（密码、token）
